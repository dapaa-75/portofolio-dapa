Dava Rianto — Portfolio
Nama Produk Dava Rianto Portfolio Website — website portofolio pribadi yang digunakan untuk memperkenalkan profil, keahlian, pendidikan, pengalaman, dan cita-cita.
Fungsi Utama Website ini berfungsi sebagai media untuk menampilkan informasi mengenai diri saya sebagai siswa Rekayasa Perangkat Lunak (RPL), keahlian di bidang IT support, networking, dan software development, riwayat pendidikan, pengalaman belajar, serta minat di bidang sepak bola. Website juga dilengkapi dengan kartu identitas interaktif dan animasi untuk memberikan pengalaman pengunjung yang lebih menarik.
Manfaat bagi Pengguna Website ini membantu pengunjung mengenal profil dan kemampuan saya secara lebih mudah dan terstruktur. Portofolio dapat digunakan sebagai media untuk menunjukkan identitas diri, kemampuan di bidang teknologi, serta cara menghubungi saya secara langsung.
Cara Instalasi Download atau clone repository project ini. Pastikan file index.html berada di folder project. Buka file index.html menggunakan browser (Chrome/lainnya). Tidak memerlukan server tambahan karena seluruh aset (foto & CV) sudah tertanam langsung di dalam file HTML.
Teknologi yang Digunakan HTML5, CSS3, JavaScript, Google Fonts (Bricolage Grotesque, Plus Jakarta Sans, JetBrains Mono), QR Code API.
Fitur Responsive (HP & laptop), Mode gelap/terang, Hero dengan kartu identitas ganda (footballer & developer), Animasi scroll & stat bar, Timeline perjalanan pendidikan, Section skill & bahasa, Kontak yang bisa langsung diklik (WhatsApp, Instagram, TikTok, Facebook, Email), Alamat & sekolah terhubung ke Google Maps, QR Code WhatsApp, Tombol unduh CV.
